# Synthetic Apple Health fixtures

- `synthetic_apple_health_export.zip`: 45-day compact fixture for normal parser tests.
- `synthetic_apple_health_export_large.zip`: 10,000-day stress fixture (about 2.2 MB compressed) for streaming / memory regression tests.

Both files are generated by `tools/generate_synthetic_export.py`. They contain synthetic values only and must never be interpreted as real user health data. The 10,000-day fixture has intentionally unrealistic temporal density; it is for parser stress testing, not analytics validation.
