# Local fonts

Fraunces (normal and italic), Inter, and a Chinese heading subset of Noto Serif SC
are served with this application. No browser request to Google Fonts is needed.
The original download URLs and CSS are in `fonts/sources.json`; the SIL Open Font
License for each family and its upstream location are included in `fonts/`.
The same font files and licenses accompany the isolated strength component.

Chinese characters outside the subset use the device's serif or UI fallback.
The meadow photograph is decorative; its source and license are recorded in
`overview-meadow-source.json`. Its date badge uses actual record metadata.
