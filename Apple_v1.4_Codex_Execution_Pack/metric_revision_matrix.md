## 共同验收边界

- 原 metric_id/title/unit 在本附录逐字保留；存在已证实单位错位时用 runtime_unit/next_contract_unit 显式描述迁移。
- 所有指标均继承原数据/证据/权限/版本/时间边界；完整实现不得靠伪造默认值或生理阈值绕过未知。
- 用户计划目标、设备实际步长、产品参数、预登记统计校准参数、外部生理证据的数字各自标来源，不可互相冒充。
- 原记录、动作历史版本、原始单位与来源不能被目录升级或迁移覆盖；重算生成新版本与审计。
- 当前日期窗一律明确 timezone、half-open start/end、cutoff 与信息可用时间；过滤未来/窗外事实。
- 计数/描述可默认启用；需要科学验证的推断与候选按各自条件启用，无真实校准本身不当作缺代码。
- existing_test_refs 均来自当前仓库真实参数化测试函数与 acceptance catalog；本附录不声称重新执行了全部 77 指标。
- targeted_acceptance 是本轮应新增/强化的可执行断言，不因已有同名目录条目就当作已通过。
- 没有综合加权恢复分、统一 −5% 调整、固定 N 生理真值或把重复观察当独立样本的总体精度承诺。

测试引用规则：`STR-xx-Tyy` 等用例 ID 均来自仓库真实 acceptance catalog；完整 pytest node 路径见配套 JSON。非 QAL 使用 `tests/science/test_metric_acceptance.py::test_metric_catalog[case_id]`；QAL 使用 `tests/science/test_quality_acceptance.py::test_quality_catalog_accounting[case_id]`。这些是回归起点，不能代替新增端到端反例或科学验证。
