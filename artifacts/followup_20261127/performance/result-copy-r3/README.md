## 修改与边界

- 将已验证的普通STR-11 JSON容器复制实现移到唯一的 `healthzip/copying.py`，原引擎私有名保留别名。分析缓存和请求内训练事件/会话读取复用它。只加速精确的内建dict/list/标量；tuple、子类、自定义对象仍用标准deepcopy，同一memo保留内部别名与循环。冷结果、缓存对象、不同消费者之间仍隔离，不改缓存键、失效、单次计算并发或读写事务语义。
- `period_report._fast_json_compatible` 只将容器放入待遍历列表，在容器内直接核对数值，避免把每个字符串和数值重复压入/弹出栈。大整数、非有限数、子类与深层容器的原解码边界不变；循环的JSON序列化错误仍由原序列化步骤拒绝，兼容检查不负责放宽它。
- 科学算法、数值、来源、冻结格式和旧行不改。这里未引入跨工作区计算复用、关闭Python自动GC、采样或减少原任务。
