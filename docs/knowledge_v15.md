# v1.5 指标依据使用说明

直接记录的 RIR 可查看新增的定义和测量限制，引用会显示 2021 作者预印本身份。系统按实际结果判断记录类型；RPE 换算、混合记录、区间 RIR 或未知条件不能借这些新依据获得来源解释权限。RIR 差仍是主观记录比较，不能当作能力或恢复已改善的证明，也不生成统一个人校正。详情见 [RIR 依据说明](v15_rir_preprint_evidence.md)。

离线评测若要测到页面默认的“已审核指标依据”路径，应显式使用 `--candidate-scope reviewed_metric`，并在Gold冻结回执及索引发布中固定范围版本。工具默认 `all` 继续兼容旧运行；已审核范围不能用于衡量全语料的新来源发现能力。公开服务身份已脱敏，完整地址及配置只留本地。命令、有限新来源对照及仍开放的验收见 [范围评测说明](v15_scoped_prospective_evaluation.md)。

本地知识库为已计算指标提供来源依据。训练记录和科学计算照常运行，知识不足时仍可以查看确定性计算结果。当前版本及未完成项见 [交付状态](v15_delivery.md) 和 [目标验收清单](v15_goal_acceptance_audit.md)。

## 在分析页查看

1. 导入自己的记录，在分析页生成结果。
2. 展开「指标的原始依据与解释」，选择分析功能及当前已有的指标。
3. 如实填写已明确的人群和测量协议；未知时留空或选择尚未说明。整场sRPE还需确认实际量表和训练后采集时点，不能用逐组RPE代替。
4. 选择本地词项、语义、混合或混合精排，点击查找原始依据。
5. 查看来源、原文、定位、适用范围、缺项及审计。缺少必要依据时会显示证据不足。

心肺和女性周期现在分别可查看「来源报告的VO₂max记录」和「已导入的月经类别记录」，并通过同一入口查找原始依据。这是与原77项明确区分的两个观测扩展；只回顾已导入的来源记录，不能推断VO₂真值、周期阶段或个人训练处方。两项目前仍缺生产审核绑定，知识不足时明确拒绝来源解释。

## 联网与本地资料

词项检索可以离线运行。语义检索和精排需要知识根目录的 `model-services.json`，模板见 [模型配置](examples/model-services.v15.json)。模板默认关闭资料联网；只有明确授权、配置好服务后才开启。端点、模型、版本和部署epoch按本机实际填写，凭据放在忽略的本地配置或环境变量中。

资料模型只接收固定指标任务和允许处理的公共证据，不发送个人数值、私人备注或用户身份。页面上发送结构化个人结果给解释服务的勾选是另一个授权，默认关闭。

PDF、全文、向量和两个知识数据库默认保存在本地，不能随代码上传。许可未知、第三方范围不清楚、撤回或待复核的资料不能因模型可用而绕过权限；NC资料限已声明的本地非商业用途。

## 如何理解结果

`evidence_context_supported` 表示当前来源解释所需的最小审核合同满足，可以查看一般来源解释；不证明个人效果或授权个人数值处方。`insufficient_evidence` 会列出缺失的证据类型、领域、适用条件或冲突。纯确定性计算可能显示 `not_required_deterministic_computation`。

`retrieval_degraded` 表示模型不可用、部分索引缺失或有单元无法进入模型预算。系统保留可用的本地证据，并明确记录降级原因。来源解释是否可用还要单独核对证据，不从模型排名推导科学权限。

精排采用完整单元的多个重叠窗口，因此可能需要多个模型请求。单个过长单元保持原文并明确标为未精排。最终在同一K片段预算内选择完整审核主张；缺少依赖、依赖撤销、依赖循环或适用性未知时不会补全结论。依赖范围和限制随解释显示。

## 命令行与维护

```bash
.venv/bin/python -m healthzip.knowledge metric-profiles
.venv/bin/python -m healthzip.knowledge build-vectors --batch-size 16 --workers 4
.venv/bin/python -m healthzip.knowledge metric-retrieve .local/request.json --mode hybrid_rerank
```

`request.json` 必须使用已经计算的完整规范MetricResult；请求字段和迁移步骤见 [迁移与运行](v15_migration.md)。向量构建是显式维护操作，按输入哈希与模型身份复用；普通查找不重新嵌入整本教材。变更模型权重后更新部署epoch，不将未核验权重宣称固定revision。

若完整原文被保守字节上限排除，可在核验实际服务能力后配置同源分词服务及token容量，按完整输入的实际token数准入。两个可选字段默认关闭；不能仅提高字节上限或截断原文。当前服务实测21个单元中18个可完整处理，另外3个表格的完整原文仍超出容量。

超长JATS表格现可在显式续建时按完整行组建立结构索引。查找仍显示完整原表，并提供命中的行列位置；标题、表头和脚注保持上下文。子索引不齐时明确降级，不把部分行当成完整覆盖。旧冻结发布保持原状，需使用新索引时另建发布ID；结构索引成功不等于来源已获新审核或科学结论已获验证。

更新前按 [备份恢复步骤](v15_migration.md) 同时备份两库和原始资料。冻结发布保留当时成员，当前来源撤回或审核撤销仍可阻止使用。旧评测失败记录保留；已公开案例回放属于开发检查，不构成新的独立检索验收。
