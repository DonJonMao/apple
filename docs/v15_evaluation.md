# v1.5 检索评测（尚未完成独立验收）

旧 visible development、固定 source-family holdout、独立 AI 原结果和后续已知题开发回放均保留原身份；本轮不得回写它们来制造提升。

当前已完成适用性拒绝、撤回/更正/权利阻断、冻结成员、领域完整性、逐边条件、缓存隔离、精排异常、隐私投影、事务回滚及实际页面回归。软件测试和服务连通不是 RAG 准确率。

首次真实服务烟测使用 qwen3-embedding-8b，生成64个公开片段向量，耗时9.009秒；查询3.327秒，但精排因输入超预算而实际完成0项。原失败保存在 `service-smoke-initial.json`。预算修复后的第二次烟测再生成64个向量，实际精排7项完整候选，查询20.259秒；仍因局部索引明确降级并返回 insufficient_evidence。证据见 `artifacts/v15/retrieval/service-smoke-bounded-2.json`。两次烟测均不是检索准确率。

全库增量索引已启动。第一次被旧库中一个仅含换行符的表格中止，已修复空片段排除；第二次主动停止以启用经软件测试的4请求并发，已保存向量均续用。当前运行不能称全库已完成，具体成功和排除数量以最终独占回执为准。

首份新 Gold `benchmark-gold-1.json` 及哈希回执保持冻结，共18案例、14指标。之后在 A–E 运行之前冻结扩展版 `benchmark-gold-2.json`：21案例、14指标，包含15个排名不可见的AI标注案例、1个曾有服务烟测的指标诊断、5个确定性权限探针，分别报告；不把开发暴露案例算作独立分母。标注模型也是 deepseek-v4-flash，存在共同模型偏差；资料包由实现者选择，且标注只覆盖有限原文池，不能把未标注内容直接当作已证明无关。原始模型响应留本地，移除JSON代码围栏属于明确记录的格式归一化，未改标签。

原 Gold 保持冻结；扩展版增加实际原文的历史静态规则冲突、旧来源适用性和手册公式定位案例，没有改写先前标注。A–D实验只去除语义适用性，来源权利和生命周期始终保留；E使用生产过滤。另外运行同样适用性策略的 lexical 参考 A_filtered，作为更公平的排序比较。实验只在本地副本中执行，应用API没有关闭适用性的选项。

局部性能对照 `metadata-projection-performance.json`：STR-12 完整元数据8.969秒、窄投影8.458秒；设备总能量36.689秒、26.536秒。两项证据语义输出哈希相同。每项仅测一次，隔离的是元数据投影，不是v1.4与v1.5准确率对比或P95。

新评分器 `knowledge/retrieval_evaluation.py` 按精确来源/版本/片段 ID 评分，保留 Recall@K、Precision@K、MRR、nDCG@K、Claim Coverage、路由、精确定位、适用性错误、无效证据、冲突和拒绝的真实分母。无 Gold 或无必需主张时为 null，不填造 100%。A–E 的原始结果需与同一冻结 Gold 完全同案例集；输出以 exclusive create 保存，旧运行不能覆盖。

最终固定输入整仓回归已完成：1499 passed in 486.10s，Ruff通过，运行期间274份输入无变化。见 `artifacts/v15/verification/regression-page-protocol-final-3.json`。1495项通过的一次早期回归因期间代码修改仍保留为输入不稳定，不能替代这次最终回归。另已在仓库外的核心依赖隔离环境安装wheel，131份源码/资源逐字节匹配，并验证确定性计算跳过检索、空知识库拒绝解释及旧v1.4核心流程。wheel构建仅重新生成了setuptools的SOURCES.txt，产品代码、测试、工具和配置未变化，单独记录于 `regression-inputs-at-delivery-1.json`。

仍未完成：全库索引条件下的五领域及跨领域 A–E 实跑及真实失败分析。因此目前不能宣称 hybrid 优于 lexical，也不能宣布 v1.5 检索质量最终通过。A与A_filtered已在冻结语料上完成词项阶段；索引完成后复制并逐字节核对同模型文档向量，再计算B–E。B–E按变体分配到四个隔离进程，避免A–D的适用性消融影响生产E；固定查询向量预热。最终执行回执将记录实际顺序；延迟只作单次观测，不作顺序、并发或P95性能比较。
