# 工作区切换与 SQLite 写锁

正常打开当前数据库只读取初始化标记，不创建写事务。`Repository` 每个连接仍启用外键并注册训练事件触发器使用的时间函数；已有 WAL 库不重复切换日志模式。实际写入使用有界的 30 秒 SQLite 等待，未开启脏读，也未关闭锁。

## 初始化与升级

`schema_version=5` 不能单独证明所有增量迁移已完成。`repository_migration_revision` 在全部迁移成功的同一事务中提交；旧库或缺标记的 v5 库执行一次完整兼容迁移。等待 `BEGIN IMMEDIATE` 后重新检查标记，避免两个连接重复升级。更高版本在写入前拒绝，迁移失败或取消会回滚并关闭连接。

后续任何子迁移变更都必须递增 `REPOSITORY_MIGRATION_REVISION`，即使根 schema 版本仍为 5。单独调用子迁移的兼容入口保留。

`TrainingService` 独立核对训练初始化版本、真实种子字节 SHA-256 和现有查询投影版本。冷初始化在一个保存点内完成迁移、原有种子填充及标记；已有种子内容继续使用原有保留策略。暖初始化不写数据，也不提交调用者尚未保存的事务。训练初始化条件变化时必须递增其初始化版本。

## 保存和取消

分析缓存先完成递归遍历、JSON 编码及全部参数行准备，再批量写入短事务。规范分析运行仍按原语义独立冻结；缓存批次失败不删除已经冻结的运行。运行保存、缓存保存和通用事务均处理取消异常，释放自己持有的锁，并保留调用者已有事务中不属于本批次的编辑。

SQLite 仍然只有一个并发写入者；修复避免在普通连接初始化和大量 Python 计算期间占用该写锁，不改变科学指标、来源权限、时间窗口或历史记录语义。

工作区路由采用明确名称，避免新增工作区后列表下标错位，导致分析、营养、周期页面显示其他页面的内容。

数据质量、运动、营养、周期工作区只调用各自既有计算，继续保存对应卡片和特征并核对声明是否已失效。浏览这些页面不再顺带计算或冻结未展示的全套 77 项指标；其他完整分析入口、既有指标定义和历史冻结格式保持兼容。

心率 / HRV、睡眠、体重 / 有氧也通过独立工作区入口只计算需要展示的规范指标。心率继续使用 `STATE-RHR` / `STATE-SDNN`，睡眠使用 `STATE-SLEEP-24H` 及原按来源汇总的睡眠序列，体重使用 `BODY-MASS-DAILY` / `BODY-MASS-TREND`，不回退到旧版混合来源统计。快照保留统一截止时间、窗口、时区、可见修订和来源。限定范围元数据与完整分析身份分开；睡眠汇总只包含该范围的事实，不能作为完整身体状态报告。VO₂ 延用原有当前有效记录视图，其范围单独标明。

限定工作区有独立缓存身份，包含范围版本、工作区、窗口、时区及截止时间，并沿用数据库修订失效和一分钟自动刷新规则。复用时保留原计算截止时间，不复用完整分析缓存或改写既有冻结结果。必要的冷初始化在读取缓存修订身份前完成，避免初始化标记变化导致首次结果马上失效；不会把计算期间发生的数据变更重新标记成同一快照。

此前心率等页面在绘制卡片前等待全套指标、能量来源审计和工作流完成，后台可能持续计算数分钟而没有异常日志。新入口避开这条无关计算路径，继续保存页面卡片、核对声明失效提示，不创建完整 `analysis_run` 或工作流运行。分析与报告入口保留完整计算。

能量区间冲突检查使用索引遍历，避免为每个区间复制其后全部区间。循环顺序、冲突归属、累加及全部数值来源保持一致；45,000 条非重叠合成区间的前后完整输出已逐项比较相等。完整分析继续保留原有逐来源数值审计，因此大窗口首次分析仍可能较慢。

## 回归证据

所有公开测试使用隔离合成数据库，真实身体数据与运行日志不进入仓库。

- `tests/integration/test_repository_open_concurrency.py`：真实写锁下暖开库、版本拒绝、旧 v5 原子升级、并发升级锁后重查及取消回滚。
- `tests/training/test_initialization_locking.py`：暖服务不写、每连接函数与真实事件投影、种子版本变化、外层事务和并发冷初始化。
- `tests/integration/test_analysis_persistence_locking.py`：准备阶段仍允许另一连接写入、批次失败和取消、提交失败时保留调用者编辑及冻结结果。
- `tests/integration/test_workspace_switching.py`：完整 `app.py` 路径切换全部 12 个工作区；另一个连接持有写锁时总览仍可重新加载；营养与周期保持各自实际数据。
- `tests/integration/test_workspace_analysis_scope.py`：限定工作区与原规范计算的指标、来源、时区及修订可见性一致，查询类型受限，睡眠与体重保留来源分流，不生成完整分析冻结。
- `tests/science/test_energy_interval_scaling.py`：嵌套、同起点、邻接、多流和无效边界的原冲突顺序，以及数千条来源的完整保留。
