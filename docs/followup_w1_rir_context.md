# W1 普通训练的直接 RIR 资料接线

从 `64cdd53` 继续。此前 S4 只绑定 STR-10/STR-14，W1 页和报告只将问题编号传给资料服务；已有普通训练实际记录与 RIR 定义/方法限制没有接通。本次复用原主张及全文，不改训练统计或处方。

在 **复盘 → 问题分析 → 同动作完成表现 → 依据与原文**，本期所有普通完成组均有直接、精确填写的 RIR 时，可查到其定义及研究方法限制。0 是实际填写值。未预指定参考、物理条件未知不阻断定义说明；未知条件仍不能变成可比组。周期报告使用同一问题事实，保留来源和限制。

## 数据流和门禁

`TrainingService.events_as_of/history_as_of → body_questions._training → question_context.evidence_observations → question_sources(computed_question=question) → metric_retrieval`。原普通轨迹仍由 `ordinary_review` 生成。新增本地投影只保留组身份、修订、时间、原努力字段；不换算 RPE、不调用第二套统计引擎。

派生资格逐条核对投影与普通轨迹的完整记录集合、数量、日期、修订、session/动作实例、RIR/区间，以及窗口、真实可见截止、来源筛选。每一条必须是完成组且 RIR 为有限非负数、非布尔值、无区间、限定符为 exact/未设、无转换标记。缺失、混合、区间、只有 RPE、损坏投影均只限制这两条解释；独立有效资料和实际完成量继续显示。自由 `context.metric_evidence.direct_rir_only=True` 不能放行。

`question_sources` 的答案选择、首次检索、一次本地补检索和本地冻结适用上下文使用同一派生规则。仍是 6+6 段上限，完整证据组不可拆开。真实公开候选投影中直接 RIR 的两条解释及既有其他说明共 11 段。个人事实、日期、组 ID、来源筛选和投影不进入网络查询或公共检索审计。

页面资料缓存加入问题 `fact_id` 和答案需求版本；换范围后先清除旧事实的资料，用户再查本范围。报告只增加 `computed_question` 参数连接，冻结结构不变，历史内容不重写。
