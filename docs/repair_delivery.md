## 数据流与统计边界

身体详情与问题页共同使用 `_points → _daily_summary → period_statistics`，显示完整本地日代表值的期间中位数、覆盖及前期差；不会把末次减首条冒充期间变化。三晚 5/6/10 小时显示中位数 6，真实均值仍为 7；心率原始 62.3333 保留，显示 62.3 bpm。展示舍入不进入计算。步数与步速分别保留，周期症状只用实际记录，不推断相位。

`render_questions → analyze_questions → question_views` 批量读取依赖；`create_report → period_facts/review_analysis + period_questions → analyze_questions` 冻结同份问题结果。后者仍保留旧 canonical 77 项指标、全部训练任务、专项工作流及历史比较，不删除科学计算换取速度。W8 依据实际记录或启用状态，设备事件入口继续独立展示。

高级专项仍允许“当前修订回看历史”和人工声明主要睡眠片段；它们本来就不是普通问题页的截止时可见记录/期间中位数。报告明确保存 `analysis_identity` 和 `report_comparison_context`，在开头及相应问题标明差别，不把晚导入记录回填为当时已知，也不改变用户声明片段。独立反例验证当前回看有60 bpm、截止时问题无该晚到记录，以及人工片段300分钟、同来源期间中位数450分钟；各自原值冻结。此两种不同身份不计作“同口径数值一致”通过项，也不宣称已经合并为一种统计。

行动页 `followup → evaluate_action`、W4 `action_observations → evaluate_action`、报告 W4 消费同一结果。主要身体观察两期均按日代表值的期间中位数；训练按真实动作/条件/组位/负荷分层后比较实际完成次数的中位数。测量过程行动主要核对真实条件与覆盖；检查任务可用本人完成反馈。窗口、计划复评与实际执行是三种不同信息，不把未执行期间的变化归因于行动。

普通训练保持同一动作身份、器械、侧别、ROM、设置、负荷口径、组类型和组位。未知不等于相同，同场重复实例不后验挑最佳配对，RIR 空值不等于 0；负荷和次数取舍分别描述。等时长前后阶段、6 小时采样桶和默认行动窗口是明确的产品显示/安排选择，不是生理阈值。原 STR-11 参考要求保持在依赖它的专项内。模型仍使用原 `calendar-gap-ar1-reml-profile-1.1`，没有为本次修复临时换科学方法。

## 新报告、永久引用与兼容

新报告版本为 `joint-period-report-2.0.0`。正文包含主要变化、目标及实际训练、适用问题、上次行动和下一步。未知条件任务按数量/缺项概述；没有删除任何原始任务来缩短正文。页面按章节、问题、动作及每页 50 条记录浏览；旧长正文也按语义章节分开，不再字符切片包进代码块。

同一 SQLite 增加 `report_content_object`，内容地址包含工作区路径/inode、用户、对象种类和完整冻结内容。报告行保存 `frozen-report-references-1` 清单及独立版本身份；canonical 当前结果引用已有不可变 `analysis_run`，普通轨迹及已选证据原文按内容复用。对象是历史记录，不是可淘汰缓存。显式再次生成产生新的 `report_id`，同输入复用相同内容；每次冻结前重新核查健康/训练/行动及知识修订。

`load_report` 自动解析新引用，旧 inline 格式按原内容读取，不迁移重写。行动仅追加 `definition_json`、反馈 `execution_json`；旧 NULL 定义保持未预先记录，不编造历史标准。数据库增量迁移修订号为 7（schema 主版本保持 5）；行动及反馈触发器更新 `review_action_version`，只有执行反馈改变也会让新报告失效重算。

打开历史报告时单独核对唯一主张/版本及其依赖来源的当前状态。已撤销、停用、来源撤回或待复核分别提示，原正文和原证据不变；当前资料库读取失败显示无法核对，不冒充科学撤销。切回全部来源的显式空筛选会清除旧选择；新库缺省时钟正规化为0，知识库首次惰性准备在冻结修订前完成，避免正常初始化被误报数据变化。资料库打开失败也仅限制解释，本地问题事实保留。

“准备完整审计包”才读取全部引用对象。`healthzip-frozen-audit-2` 包含报告清单、唯一内容对象、工作流结果和分析对象；`reconstruct_report(bundle)` 可在没有原库、临时目录或网络的情况下还原 public report，测试逐字段相等。审计包包含完整冻结观测、方法及所选资料；它不是当前建议。旧报告原文不随修订/删除/撤销改写。

缓存继续使用已有工作区隔离、修订依赖、有界容量、同键合并和清空代际保护。新增优化只在同次报告请求内共享只读事件/科学结果；公开 session 返回值最后复制，嵌套修改不能污染缓存。临时资料或模型失败不进入成功热缓存，同键显式重试仍可重新执行。

可选周期启用偏好也进入报告键，生成中改变偏好会拒绝保存过期结果。冻结内容在引用化前一次检查全部数值，内部 `content_decoder` 提示允许安全对象使用已有快速JSON解码；大整数、非有限值、旧无提示清单和解码失败继续走标准解析，原始值不损失。提示不出现在公开报告对象；若未来支持外部清单导入，必须重新检查，不能信任外部自报提示。
