# 力量训练工作台

本页说明力量工作区的手机与桌面交互。数据继续写入既有 SQLite 训练表，所有修改经 `TrainingService` 的事件、修订和权限边界；本轮没有增加训练建议规则或科学公式。

外层页面与其他工作区保持同一标题和顶部导航，切换力量不会改变整页布局或挪动工作区入口。顶部同样提供可缓存的本周、本月[当前数据分析](workspace_summaries.md)，训练卡片使用局部样式。

## 日常操作

进入力量页后，首页显示周一开头的月历。有未结束训练时先显示“继续训练”；多场未结束训练分别保留。选择某天只查看当天的独立会话，没有记录的日期显示“暂无记录”。开始训练始终使用真实当前时间，浏览过去日期不会把新训练补录到过去。

每天的训练卡片都有“删除训练”按钮，空训练也可直接删除。点击后先核对训练再确认，取消不会更改记录；删除后可撤销，训练统计按真实修订更新。

“开始训练”以自由训练为主，可选部位与名称，也可以使用已有计划。自由训练开始后直接打开动作选择。搜索支持已有中文、英文和别名，部位及器械来自目录。动作可多选，切换搜索、筛选时保留选择顺序；关闭选择面板不会添加动作，点击“添加 N 个动作”才写入会话。明确的“再次添加此动作”保留同场重复实例能力。

训练中每个动作是一张卡片，只有当前动作展开。组号、重量或刻度、次数/秒/米、RIR 与完成按钮集中在紧凑行。自由加入且无计划组的动作自动创建一个全空草稿；计划自带的组不重复新增。新增一组创建空白草稿，复制上一组或历史记录则是单独的草稿操作。复制不继承实际 RIR、质量、疼痛、发生时间、完成或参考身份。

填写数值后，可以保存草稿或确认完成。RIR 留空是未知，`0` 是明确记录，重量允许合法小数；时长和距离使用各自字段。主行保存保留已经填写的高级字段。只有收到后端成功回执才显示已保存或完成，失败与版本冲突保留输入。已完成组修改走更正，不创建第二条事实，也不会因再次点击完成重写结束时间。

“动作历史”展示同动作最近一次实际训练的全部已记录组，继续采用既有最近整场历史选择逻辑；首次记录会明确说明。可选建议与本次输入分开，建议不会替用户填写实际值。建议和资料服务不可用时仍可记录。查看建议是明确操作，每个数字输入、展开卡片和每秒计时都不会触发全套分析。

顶部返回只离开当前视图，训练仍然可继续。结束训练先显示完成与未完成组数量及摘要，可选填写备注、整场 sRPE、实际量表与时长。结束不会把草稿或跳过组改成完成。历史详情仍可更正、删除和撤销，冻结建议与报告保留原结果。

## 次级入口

底部提供加动作、训练备注和更多。组的类型、停止原因、质量、疼痛、RIR 限定词、RPE 量表、时间和组间关系进入组详情。动作口径、器械、侧别、ROM、档位等进入动作设置。目录默认值不等于用户已确认，未知口径不阻止普通记录，也不会获得数值建议权限。

模板、动作维护、历史与冲突、导入导出、离线记录器、原分析等功能保留在管理入口。未打开的管理视图不执行完整渲染。

## 状态与时间

组件使用稳定的会话 UUID、动作实例和组 UUID。请求带稳定命令 ID，重试保留原 ID 和载荷。Python 验证修订并调用原训练服务，成功、错误和冲突回执均来自真实后端。

已保存草稿从数据库恢复。浏览器本地未提交输入按数据库隔离身份、用户、会话、组分开保存；它们仍标记为未保存，不能冒充数据库成功。浏览器清理站点数据后，本地未提交输入可能丢失，数据库草稿不受影响。私人输入不发送外部服务。

训练时长由真实会话开始时间计算，未知开始时间保持未知。JavaScript 每秒只更新显示，不写数据库、不触发全页刷新或分析。休息继续用原计时服务；没有设目标时显示正计时，不自动写入 60 秒，也不会伪造组开始时间。

## 本地组件与运行

主应用仍由 `app.py` 和 Streamlit 启动。力量主区使用局部双向组件，生产资源位于 `src/healthzip/ui/strength_component/`，由 Streamlit 本地托管。前端只负责展示、编辑状态及明确命令；业务验证、事件、修订和科学计算仍由 Python 完成。REST token、CORS 和离线记录器接口没有因组件放宽。

组件采用原生 HTML、CSS、JavaScript，无 npm 构建、CDN 或临时开发服务器。资源随 Python 包分发；正常运行使用：

```sh
python -m pip install -e '.[ui]'
python -m streamlit run app.py --server.address 127.0.0.1
```

组件资源被打包进入 wheel，构建命令为 `python -m pip wheel . --no-deps`。浏览器测试额外需要 Playwright 与 Chromium，它们不是生产依赖。

## 浏览器验收

验收入口为 `tests/training/strength_workbench_browser_check.py`，合成资料由同目录 `strength_browser_fixture.py` 使用真实训练服务创建。脚本在临时工作目录启动完整 `app.py`，默认数据库、知识库、日志均隔离，测试结束关闭服务。实际截图与逐项结果写到指定输出目录；不读取生产 `.local` 或 Apple Health 导出。

运行方式及本轮实际结果见 [验收记录](strength_workbench_delivery.md)。截图属于模拟 Chromium 视口，不能据此声称已经验证真实 iPhone 原生数字键盘、软键盘安全区或 Safari 行为。
