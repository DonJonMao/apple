# 心率、睡眠依据查询结果修复

2026-11-20，针对产品改版提交 `42f43dc` 的后续修复。用户在心率、睡眠点击“查阅依据并解释变化”后，立即看到“范围或记录已更新，旧解释不再用于本期数据。”，无法查看结果。

## 原因与修复

1. 页面局部组件持有旧事实快照。在事实缓存的 300 秒有效期结束后点击，原实现先提交旧快照，再整页刷新；刷新生成新的截止时间，刚提交的任务立即不匹配当前页面。现在按钮先记录查询意图，整页取得当前事实后才提交任务。真实浏览器通过缩短缓存有效期复现了原提示，最终验收用合成库强制过期验证同一边界。
2. 原知识库版本标识依赖 SQLite 数据文件和 WAL 的大小、修改时间。检索审计写入或连接关闭时的 checkpoint 也会改变标识，导致有效结果被隐藏。现在来源、审核、主张、规则、领域和文档索引使用持久修订号；查询审计及查询向量缓存不影响该修订。跨进程撤回仍使旧结果失效。结果保存实际核对过的修订号，避免后续写入把旧结果标成新版本。
3. 心率、睡眠的查询状态现在按数据工作区和页面分别保存，切换页面不会覆盖另一页的任务。
4. 检索完成后显示查询指标数、原文数、满足解释条件的指标数。缺少适用人群、测量协议或完整审核依据时显示具体原因，原文可展开核对；不把不适用主张展示成已批准解释。符合条件的已审核说明无需模型也能显示。

此入口执行本地依据检索，模型解释另受配置和联网授权控制。本次运行环境没有配置健康解释模型，私人健康联网授权未开启；修复不更改这些设置。没有模型回答时页面明确说明。事实卡和趋势继续独立显示。
