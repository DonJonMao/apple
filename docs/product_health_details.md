# 健康详情与异步解释改版

2026-11-20 产品体验改版的详情页合同。本文取代旧 `daily_ui.md` / `workspace_summaries.md` 中表格优先、体重与有氧混页、独立周月摘要和侧栏范围的界面描述；既有科学指标和来源权限继续有效。

心率、睡眠、体重、有氧采用同一顺序：页面标题及主范围、来源分开的数值卡、趋势、本期关键变化、具体记录建议、可选来源解释、默认折叠的原始明细与分析依据。只有一套主范围，主程序将本周、本月、近30天或自定义天数传给 `analyze_workspace`，这些区域消费返回的同一快照。运动页也使用 `scoped_workout_inventory` 返回的同一时态窗口，展示实际运动量与运动记录；有氧页只讲现有 VO₂max 观察，不复制运动历史。

已实际查看 Lift 的官方 stats 截图与 Liftosaur 的 workout-screen-overview 截图。采用数值优先、克制卡片、明确留白与次级明细层级；没有复制代码或图片，没有引入人体恢复热图及其算法。图表与全局石墨/青绿色主题一致。

## 数据与显示

- 静息心率与 HRV（SDNN）保持独立；不同来源、设备、协议与版本仍分别汇总，不合成“改善”或恢复评分。SDNN 不与 RMSSD 混用。
- 体重页只呈现体重，有氧页只呈现本期 VO₂max。旧称重与旧 VO₂max 仅在标明实际日期的历史参考展开区出现，不进入本期卡片、图表或变化。
- 本期变化明确称为“首末记录差”，附真实起止观测日期；它不是与完整前期的同比，也不推断原因。只有一个点时直接说明不能判断变化。
- 图表只显示真实观测日期；稀疏数据使用点，不为缺失日补零或画虚构连线。长范围每来源最多约 400 个实际极值点，保留端点及各段高低值并说明显示降采样，卡片仍使用全部有效日值。VO₂max 同日多次观测保留实际顺序。
- 原始明细默认折叠，每页最多 50 条。无 Plotly 时仍能展开数值。空状态提供导入入口，只有旧数据时显示实际最后观测时间。缺失、零时长和有效零值分别处理。
- 运动时长/能量缺失不补零；周期汇总和明细均来自本页的记录快照。未版本化 Workout 附表不冒充可重放的历史能量。

## 解释与复盘

`health_explanation.py` 使用两个有界后台工作线程，最多 8 个在途任务、32 条缓存记录和一小时过期兜底。同一请求可合并；事实页不等待检索或模型。后台工作仅传不可变计算快照，知识库及必要声明校验均在工作线程内建立独立连接，不跨线程共享页面的 SQLite 连接。

健康解释与原分析页、指标依据查询均在明确操作后执行，局部 fragment 轮询。未配置知识库、证据不足、任务失败及来源变化各有真实状态；失败可重试。数据、范围、来源、工作区、声明、提示版本或模型配置改变后，旧解释不配给新数字。性能计时字段不参与解释身份。来源授权在查询前后检查；旧知识库第一次查阅产生兼容迁移时，丢弃原回答后最多重新读取一次。

健康详情复用既有已确认适用声明与规范指标中的测量协议；失效声明不会恢复旧权限。模型联网授权沿用设置中的会话业务状态，可撤回。检索不以待审核种子冒充已验证依据；模型仍通过既有最小摘要及确定性事实验证边界。当前来源一般解释与个人变化原因分开呈现。

`analysis_page` 普通呈现不再调用 `persist` 或 `review_analysis`。完整分析、工作流和报告保留显式更新或生成操作。原有指标依据筛选功能保留，查阅改为异步。

复盘的问题分析可独立打开“前置动作变化，后续表现是否不同”：明确选择两场、前置动作和后续动作，调用既有服务核对实际顺序、完成工作组、负荷口径、次数和 RIR，再展示可能解释及下一步。逐组值、缺项和引用默认折叠。历史审核回执不能授权当前解释；可选查询重新核对当前知识。该 UI 不先运行全部指标，不阻塞力量录入。

桌面 1440px 与手机 390px 的实际颜色合成、键盘焦点和触控测量见 [视觉可访问性回执](../artifacts/product_redesign/visual-accessibility.json)。首次测量发现 caption 祖先透明度导致 3.775:1 对比度、部分按钮 40px、数字输入 14px 字号；修复全局样式后重测通过，caption 为 8.641:1，所测主要控件至少 44px，数字输入 16px。该回执针对列明的实际元素，不代表完整 WCAG 审核或真机体验认证。

睡眠页面的主平均与曲线仍来自所选日历范围；已有固定“过去24小时”科学指标使用其独立窗口，在分析依据和对应来源解释旁另行标注。显式“指标依据”保留无个人观察时查阅一般来源定义的能力，协议未知与已明确协议的权限仍分别验证；每次重绘产生的 `MetricResult.computed_at` 不改变事实缓存身份，科学截止、窗口、数据、来源及算法版本继续参与。
