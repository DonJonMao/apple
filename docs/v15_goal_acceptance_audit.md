## 六功能调用链审计

实际路径为 `analysis_page.render_analysis` → `metric_evidence.render_metric_evidence` → `KnowledgeWorkbench.explain_metric` → `retrieve_for_metric`。统一入口要求已计算、同身份、经过合同校验的MetricResult。配置含六个功能，但各功能对应的原77项指标数为：心肺0、长期18、恢复16、代谢11、周期0、力量34；指标可多功能复用，这些数不能相加作为77项覆盖率。

旧 `analytics.core.vo2_analysis/cycle_analysis` 继续保留兼容身份。新链路直接读取health_sample修订账本，形成 `OBS-VO2-REPORTED` 和 `OBS-CYCLE-RECORDS` 两个规范观测扩展，保存于 `observations`；原 `metrics` 仍77项。心肺保留来源报告值和原始单位依据，周期保留未解释的原类别，不发明VO₂真值、出血天数、周期阶段或训练处方。实际分析页可选择两项并调用统一解释入口，生产审核缺项仍拒绝。完整边界见 [来源观测接入](v15_source_observations.md)。
