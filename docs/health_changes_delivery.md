## 已实现的统计与兼容合同

- RHR 专读日静息心率字段。普通心率单独显示真实样本、每日分布、设备/已知情境和计数，不冒称时间加权全天均值。SDNN 与 RMSSD 分离；SDNN 每个同条件日期先取中位数，再对日值等权计算期间中位数和四分位数。新版 `daily-physiology-2.0.0`；统计是产品描述选择，不是医学阈值。
- 前期默认不重叠；日历周/月使用上一周期相同已过长度。个人参考复用既有28日设置，严格位于评价起日前。当前未完整日期和不完整起始日单列，`complete_window` 给出完整日统计的实际边界。缺日不补零、不丢记录凑齐；零分母不算百分比，MAD为零不算z。体重原期间均值、活动与力量原统计保留。
- 原始起止、原时区偏移、分析时区、导入/可见时间、协议与未知条件都可追溯。新 Apple 导入增量保存原始时间字符串，不改变已有去重指纹；旧记录缺少的原结束偏移保持未知。历史计算使用当时可见修订，原冻结报告不重写。
- 睡眠在同来源/设备/协议/版本内连接连续观测事件，按事件结束本地日期归属；时长用 UTC 实际差，支持夏令时23/25小时日期。父子 asleep 区间取并集，awake冲突显式扣除并保留仲裁信息；分期冲突与未知分期不强行分配。不同来源独立呈现、可筛选、不跨源拼完整一夜。不自动把短片段判为午睡，也不把记录终点叫实际起床。版本 `sleep-connected-observations-2.0.0` / `health-period-summary-2.0.0`。
- 睡眠页提供逐日总量、截止前24小时、已明确声明的冻结主睡眠。每种口径使用自己的图、范围及解释身份。冻结主睡眠按工作区隔离；当前浏览器会话可返回查看，重启后不会自动恢复身体页的最近选择，底层声明及历史分析仍保留。
- 联合分析按睡眠结束日对齐当日RHR/SDNN，显示真实重叠日期、同期完成组数及已填疲劳；没有饮酒、旅行或症状记录时不编造。周/月Markdown和页面复用同一事实投影，保留历史冻结身份。

## 缓存与性能

事实、解释各自加载；页面不等待模型。统计缓存按工作区文件身份、相关来源修订、范围、时区、来源筛选和算法版本失效；新查询分区缓存复用稀疏指标月块，月块只是查询分区，不改变观测日期/睡眠事件。自动请求保存截止时点并在相关修订、日期变化或300秒到期时刷新；前期/参考窗口可以复用相同可见性截止的查询块。检索缓存按知识与审核权威修订、用途条件、冻结发布及预算失效；生成任务继续按事实/上下文/知识/提示/模型/授权身份隔离并去重。显式清空期间完成的旧任务不能回填缓存。

本次还修复完整分析缓存受检索日志/WAL整理误失效的问题，改用来源/审核/索引修订。跨工作区、撤销证据、并发变更后返回前复核继续保留。所有缓存有界；普通心率所有有效记录参与分布，最多400个真实点用于显示，不用降采样计算统计。

固定环境为同机 Linux aarch64、Python3.11、SQLite WAL、Chromium158。复用100,000/1,000,000条合成健康记录，各带10,000训练组；每级5次冷计算、30次热访问。操作系统缓存未清空，冷启动与运行中冷范围分开。
