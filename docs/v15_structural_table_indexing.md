# 超长 JATS 表格的结构索引

`metric-hybrid-1.5.2` 在原 SourceLibrary 中增加可重复构建的 `retrieval_projection_set`。它保存原 Span、原文哈希、结构快照哈希、投影版本及子输入的哈希/定位清单，不创建新的 Source、Span、主张或审核。完整正文及向量继续只在本地保存。

## 从原表到索引

仅在完整原文不能进入 Embedding 输入预算时，显式 `build-vectors` 才尝试处理含有可读 `raw_xml` 的 JATS 表格。先核对当前来源资格、原始文本和结构快照的一致性，再安全解析原有 XML；DTD、实体、不支持的嵌套表、非法合并单元格和未解决的表头引用均拒绝，不能自动修复或猜测表意。

投影保留完整标题、说明、脚注、各子表明确标识的表头/表尾，以及不可分开的 rowspan 行组。行、列范围采用从0开始的半开区间；colspan、rowspan、scope、headers 和原始单元格属性均保留。显式 headers 引用对应的完整行作为有独立定位的上下文保留；前面的全 th 行或单个跨列单元格行仅作为结构上下文，不能据此推断语义继承。

一个原 Span 可以含多个同级 table。所有表头都注明其所属子表，不能把第一张表的列名自动套到后续只有节标题的表上。定位同时保留原始 Span 的来源定位和完整 owned raw_xml 快照内的相对 XPath；不将经过所有权过滤后的结构路径伪称为未过滤原文件的绝对 XPath。子表属性、行组和单元格的具体位置均可回到该不可变快照核对。

没有固定字符裁切，没有原文截断，也没有将过长的单行进一步拆成可能丢失关系的文字块。一个完整行组连同必要上下文仍不能进入模型时，整组明确失败。

## 从子向量返回完整证据

普通检索只读已有投影元数据和向量，不解析重建子输入，不进行文档 Embedding。一个原 Span 有完整原文向量时优先复用；否则必须具有与原文和结构哈希相符、版本一致的完整投影，且所有子输入向量均可用，才能以最大的子向量余弦相似度形成该原 Span 的一个 dense 名次。

缺少任一子向量时，整个父片段不参与 dense 排名，审计记录预期数量、可用数量和降级原因。不能从已经索引的部分行推断整张表已可检索。与其他候选融合时仍只有原 Span 这一个身份，不因表格行数增加而复制候选或重复占用 K。

命中结果返回完整、逐字保持的原始 Span。`dense_projection` 和 `dense_structural_projections` 记录投影集合、版本、完整性、获胜子输入哈希、行列定位和汇总方式。该定位说明为何进入检索结果，不是额外的科学审核或局部证据充分性判断。精排仍接收原始完整单元；父表不能进入精排预算时继续明确标记未精排。

来源许可、当前撤回/更正、主张审核、适用条件、冻结成员、完整主张及显式依赖继续沿既有路径核对。背景表格的 dense 命中不能自动获得来源解释权限，更不能授予数值候选权限。

## 增量和冻结

缓存仍按模型身份、用途和实际输入哈希复用。重复构建复用全部已缓存输入；来源修订时，内容和必要上下文未变的子输入可以复用，只有受影响输入需要重新生成。旧原文、投影集合和向量不删除。

新冻结索引记录当时的 `projection_set_ids`。旧冻结发布没有该字段时按空集合解释，不能自动获得后来新增的结构投影；其发布内容及哈希不变。当前来源或主张失效仍可阻止被冻结成员的使用。旧评测副本不因生产本地索引续建而改变。

## 验证范围

合成测试覆盖多子表、命名空间、合并单元格、显式表头引用、缺表头、结构错误、原文不变、增量修订、部分索引拒绝、普通查询不重建、冻结隔离及来源/权利/主张失效。真实服务索引与整仓回归回执分别保存，不能用索引成功或软件测试代替独立检索准确率和专业审定。

实际本地服务已为 E7/R6/S7 的三张原表建立104/179/32个完整结构分组，共315个新增输入。文档向量缓存44421→44736；重复构建新增0、复用315，原有27张数据库表中的既有行、318份历史工件及原冻结评测目录文件均未改变。三次实际固定指标调用分别检验SDNN、sRPE和同负荷次数变化的调用链：第一项满足既有最小解释合同，后两项继续拒绝证据不足，没有补授审核或数值候选权限。回执见 [真实索引及烟测](../artifacts/v15/retrieval/structural-table-indexing-1.json)。新增独立评测分母为0。

本批整仓1533项测试通过、Ruff通过，234份源码/测试/配置输入在整个回归期间保持原字节；真实索引调用的三份实现文件与回归输入匹配。见 [回归回执](../artifacts/v15/verification/regression-table-projection-1.json) 和 [历史工件保护](../artifacts/v15/verification/historical-protection-table-projection-1.json)。
